# FitForge — Gym & Training E-commerce Demo

A responsive portfolio project built with **HTML, CSS, and vanilla JavaScript**.

## Features
- Responsive desktop, tablet, and mobile layout
- Product categories and collection shortcuts
- Live product search and sorting by price/rating
- Product quick-view modal
- Add-to-bag, quantity controls, remove item, subtotal, and free-shipping progress
- Cart persists with `localStorage` after refresh
- Simulated checkout with a demo order reference (no real payment)
- Newsletter form interaction (demo only)
- Accessible labels, keyboard Escape behavior, reduced-motion support

## Run locally
1. Extract the ZIP.
2. Open `index.html` in your browser, or use VS Code's **Live Server** extension.
3. No build step or package installation is required.

## Publish on GitHub Pages
1. Create a public repository on GitHub.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under Build and deployment, select **Deploy from a branch**, choose `main` and `/ (root)`, then Save.
5. Wait for deployment and open the published Pages URL.

## Important
This is a front-end portfolio demo. Product details, newsletter signup, and checkout are simulated. It does not connect to a payment gateway, inventory database, or email marketing service. Product photography loads from Unsplash and Google Fonts load online.
